# Productos de Referencia

## Producto 1: SensiFlood EVX2000B-FSN

### Resumen del producto

SensiFlood EVX2000B-FSN es un sistema autónomo de monitoreo y detección de inundaciones diseñado para aplicaciones ambientales y de alerta temprana. Integra sensores de nivel de agua mediante tecnologías ultrasónicas, radar y transductores de presión, además de incorporar sensores complementarios como pluviómetros, GPS y sensores de temperatura.

El sistema permite la comunicación mediante redes celulares, satélite, LoRaWAN y WiFi, además del almacenamiento de datos y monitoreo en tiempo real mediante una plataforma en la nube.

### Aporte del producto al proyecto

Este producto aporta al proyecto **Llaqta Guardian** una referencia para la integración de múltiples sensores dentro de una plataforma inteligente de monitoreo. Además, proporciona una base para el desarrollo de sistemas autónomos alimentados mediante energía solar y con capacidad de monitoreo remoto, permitiendo mejorar la detección del incremento del nivel del río y optimizar la generación de alertas tempranas para comunidades vulnerables.

## Producto 2: Vantage Flood Station (AEM)

### Resumen del producto

Vantage Flood Station es un sistema de detección y advertencia de inundaciones que permite monitorear continuamente el incremento del nivel del agua y emitir alertas automáticas en tiempo real. Su propósito principal es aumentar la seguridad pública mediante la detección rápida de situaciones peligrosas, reduciendo la necesidad de supervisión manual y permitiendo una respuesta inmediata ante posibles eventos de inundación.

### Aporte del producto al proyecto

Este producto aporta al proyecto **Llaqta Guardian** un modelo de funcionamiento basado en alertas automáticas y monitoreo continuo de variables hidrológicas. Su diseño sirve como referencia para implementar un sistema capaz de disminuir la dependencia de la supervisión humana y emitir advertencias oportunas a la población frente al aumento del nivel del río.

## Producto 3: OTT Flood Monitoring System (OTT FMS)

### Resumen del producto

OTT Flood Monitoring System es un sistema integrado para el monitoreo de inundaciones y crecimiento de ríos que utiliza sensores radar sin contacto para medir el nivel del agua con alta precisión. El sistema incorpora registradores de datos, comunicación inalámbrica y alimentación mediante batería o paneles solares, permitiendo un monitoreo continuo y remoto de las condiciones hidrológicas.

### Aporte del producto al proyecto

Este producto aporta al proyecto **Llaqta Guardian** una referencia tecnológica para la implementación de sensores de medición sin contacto y sistemas de monitoreo remoto de alta precisión. Asimismo, su integración con fuentes de energía autónoma y transmisión de datos contribuye al diseño de un sistema confiable para detectar el crecimiento de los ríos y generar alertas tempranas en zonas vulnerables.
