# Descripción del Prototipo

El diseño mecánico fue desarrollado para alojar de forma segura los componentes electrónicos del sistema Llaqta Guardian, incluyendo el ESP32, el sistema de alimentación basado en batería recargable, la bocina de alerta, los sensores ambientales y los elementos de refuerzo estructural. La carcasa incorpora una puerta de acceso para mantenimiento y espacios dedicados para el montaje de sensores y cableado interno.
