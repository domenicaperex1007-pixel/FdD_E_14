# Descripción del Prototipo

El diseño mecánico fue desarrollado para alojar y proteger los componentes electrónicos del sistema **Llaqta Guardian**, incluyendo el microcontrolador ESP32, el sistema de alimentación mediante batería recargable, la bocina de alerta, sensores ambientales y elementos estructurales de soporte.

La carcasa incorpora una puerta de acceso para facilitar el mantenimiento del sistema, además de espacios internos destinados al montaje organizado de sensores, conexiones y cableado electrónico.

Este diseño permite integrar los componentes físicos y electrónicos en una estructura compacta, resistente y adecuada para la implementación del prototipo en escenarios reales.
